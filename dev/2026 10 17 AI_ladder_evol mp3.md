### 3.1 User-Perspective Generation Boundary Rule (`Gen 0` to `Gen M`)

**Dual User-Shift Cutoff Criterion:** Anchor `Gen 0` in modern Pre-LLM era (`~2017–2020`); declare new generation `Gen G` (`YYYY-MM` to `YYYY-MM`) in `Table 3.1` only when empirical inventory shows **both** new upper-level skill demands and downward built-in level sinking.

* **Anchor Generation (`Gen 0` — Pre-LLM Baseline, `~2017-06` to Pre-LLM Cutoff):** Start `Gen 0` at June 2017 Transformer paper (`Attention Is All You Need`) and modern pre-LLM ML practice, prior to mainstream generative LLMs.
* **Criterion 1 (New Use Case Requiring New User Skills):** New use case emerges at `Level 2..N` requiring users to learn new keywords, tutorials, or tool setups absent in `Gen G-1`.
* **Criterion 2 (Same Use Case Sinks to Lower Level / Built-In Deflation):** Use case forcing users in `Gen G-1` to operate at higher `Level L` (e.g., writing custom wrapper code to execute Chain-of-Thought, visiting separate site/Discord server to generate images when chat was text-only, or coding custom vector RAG script over PDFs) becomes **built-in** at `Level L-1` or `Level 1` in `Gen G`.
* **Criterion 3 (Contemporaneous Folksonomy Break Cross-Check):** Cross-check `Gen` cutoffs against Section 2.1 ladders to verify when old ladders broke and practitioners published new ladders; reconcile capability first-release dates (`TRL 4–6`) with mainstream production crossover dates (`TRL 8–9`).

### 3.2 User-Learning Level Boundary Rule (`Level 1` to `Level N`)

**Standardized Skill-Hour Yardstick:** Standardize vertical axis across all generations as user skill tree measured by learning hours and setup complexity (`Table 3.2`), fixing `Level 1` and `Level 2` while discovering `Level 3..N` inductively.

* **Fixed Anchor `Level 1` (`0 Hours` — Zero-Skill Casual User / High Schooler):**
  * **Rule:** Zero AI-specific study (`0 hours`), zero setup, zero-shot operation by average high schooler in default consumer interface.
  * **Empirical Check:** If zero-skill consumer wrapper exists in `Gen G`, assign to `Level 1`. Do not pre-assume empty cells before auditing inventory; in `Gen 0`, evaluate passive consumer NLP widgets (`Google Translate` GNMT, `Grammarly` browser underlines, `Gmail Smart Compose` `2018-05`) alongside missing active zero-shot generative LLM chat.
* **Fixed Anchor `Level 2` (`7–45 Hours` — 1 Weekend to 1 Full Week of Study):**
  * **Rule:** Deliberate power-user learning taking `7 to 45 hours` of tutorials/guides (prompt engineering, completion formatting, Midjourney flags, `Custom GPT` / `Claude Project` setup, `Deep Research` scoping) with zero software coding or server administration.
